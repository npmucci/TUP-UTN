# TUP-UTN

## Introducción

 Este repositorio reúne **materiales, ejercicios y proyectos** de diversas materias de la carrera **Técnico Universitario en Programación (TUP)** de la **UTN**, organizados por cuatrimestres.                        Incluye tanto **ejercicios de programación en C/C++** como **apuntes, prácticas y trabajos de otras materias**, sirviendo como guía de estudio para los estudiantes.


## Características

- Material **diverso y organizado por cuatrimestre y materia**.  
- Ejercicios de **programación con proyectos listos para ejecutar** en Code::Blocks.  
- Apuntes y trabajos en formato texto o PDF para **referencia rápida**.  
- Estructura clara que permite navegar fácilmente por cuatrimestre y materia.

---

## Requisitos

| Área             | Herramientas necesarias                                    |
| ---------------- | ---------------------------------------------------------- |
| **Programación** | Compilador C/C++ (G++), IDE Code::Blocks, librerías estándar |
| **Bases de datos** | Motor de bases de datos (MySQL, PostgreSQL, SQLite)        |
| **Otros apuntes** | Lector de PDF o editor de texto                             |

## Instalación y uso

1. **Clonar el repositorio:**  
   ```bash
   git clone https://github.com/npmucci/TUP-UTN.git
    ```


2. Navegar por cuatrimestres y materias:
Cada cuatrimestre tiene su carpeta, dentro de la cual se encuentran subcarpetas por materia y tipo de material (ejercicios, apuntes, proyectos).

3. Ejecutar proyectos de programación:
Abrir el archivo de proyecto .cbp en Code::Blocks y compilar/ejecutar según las instrucciones.

4. Consultar apuntes y ejercicios:
Abrir PDFs o archivos de texto directamente desde la carpeta correspondiente.
